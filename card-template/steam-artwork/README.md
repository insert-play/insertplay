# Artwork

Put the shortcut artwork here as PNG files. Every file is optional; a missing one keeps Steam's default.

| File | Steam artwork | Typical size |
|---|---|---|
| `icon.png` | shortcut icon (copied to the device, see the README) | 256×256 |
| `capsule.png` | vertical cover in the library grid | 600×900 |
| `horizontal.png` | wide cover (recent games, home) | 920×430 |
| `hero.png` | banner at the top of the game page | 1920×620 |
| `logo.png` | logo drawn over the hero | 640×360, transparent |

[SteamGridDB](https://www.steamgriddb.com/) has artwork in these formats for most games.

Delete this README from the card.
